Dữ liệu tự lưu trên trình duyệt. Bấm Save GitHub để commit data/project.json và chia sẻ cho team.

Tạo project mới = Repo mới

Clone web template hiện tại sang một repository mới, tạo data project trắng và bật GitHub Pages.

Setup 1 lần: repo nguồn phải được bật Template repository. Token tạo project cần Repository access: All repositories và quyền Administration: Read and write, Contents: Read and write, Pages: Read and write.
Lưu ý: token cũ chỉ có quyền Contents trên 1 repo sẽ không đủ để tạo repo mới. Token không được ghi vào repo hay file JSON; chỉ giữ trong phiên trình duyệt hiện tại.
Chưa bắt đầu.

Lưu dữ liệu phân tích trực tiếp vào repo bằng GitHub Contents API.

Bảo mật: tạo fine-grained token chỉ cho đúng repo này, quyền Contents: Read and write. Token chỉ được giữ trong sessionStorage của tab trình duyệt, không ghi vào repo hay JSON export.
